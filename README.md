# Zaalima Internship Projects

This repository contains multiple end-to-end analytics projects built using Python, SQL, Power BI, and Financial Analytics concepts.

---

# Projects Included

## 1. Consumer360
Customer Segmentation & CLV Engine

Features:
- RFM Analysis
- Customer Segmentation
- CLV Calculation
- Market Basket Analysis
- Cohort Analysis
- Power BI Dashboard
- Automated Data Pipeline

Tech Stack:
Python, SQL, Power BI, Pandas, MLxtend

---

## 2. AlphaPulse
Investment Risk & Volatility Monitor

Features:
- Stock Data Collection using yfinance
- Daily Returns Analysis
- Correlation Heatmaps
- Monte Carlo Simulation
- Value at Risk (VaR)
- Rolling Volatility Analysis

Tech Stack:
Python, NumPy, yfinance, Tableau
