# Week 2 – Quantitative Financial Analysis

## Topics Covered
- Daily Returns Analysis
- Correlation Heatmap
- Value at Risk (VaR)
- Monte Carlo Simulation

## Dataset
Stock prices of:
- Apple (AAPL)
- Microsoft (MSFT)
- NVIDIA (NVDA)
- Tesla (TSLA)
- JPMorgan (JPM)
- Bank of America (BAC)
- Pfizer (PFE)
- Exxon Mobil (XOM)
- Walmart (WMT)
- Verizon (VZ)
- S&P 500 (^GSPC)

## Key Insights
- Technology stocks showed strong positive correlation
- TSLA and NVDA showed higher volatility
- Banking stocks JPM and BAC were highly correlated
- VaR analysis identified risk levels of stocks
- Monte Carlo simulation estimated future stock movement
