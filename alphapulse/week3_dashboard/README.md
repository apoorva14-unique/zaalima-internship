# AlphaPulse – Financial Analytics Dashboard

## Overview
AlphaPulse is a financial analytics project focused on stock market performance, risk analysis, and market insights using Python and Power BI.

## Dashboard Features
- Tech stock performance analysis
- Daily returns comparison
- Banking stock analysis
- S&P 500 market trend analysis
- Interactive date filtering
- KPI cards for stock metrics

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Key Insights
- Tesla showed high volatility in returns
- Microsoft and Apple demonstrated stable growth
- Banking stocks showed long-term upward trends
- S&P 500 recovered strongly over time
