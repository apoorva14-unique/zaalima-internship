# AlphaPulse – Week 4 Advanced Analytics

## Overview
This module focuses on advanced financial analytics, forecasting, portfolio optimization, and automation using Python.

The goal of this phase is to analyze stock market behavior, identify trends, evaluate portfolio risk, and automate the financial analytics workflow.

---

## Modules Included

### 1. Moving Average Strategy
- Calculates 20-day and 50-day moving averages
- Identifies market trends
- Visualizes stock movement over time

### 2. Stock Forecasting
- Uses rolling averages to forecast stock price trends
- Compares actual vs forecasted stock prices
- Generates forecasting visualizations

### 3. Portfolio Optimization
- Analyzes risk vs expected return
- Compares multiple stocks
- Helps identify balanced investment opportunities

### 4. Automated Analytics Pipeline
- Runs all advanced analytics modules automatically
- Simplifies workflow execution
- Improves project automation
